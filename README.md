# City Lights for Vim

A dark Vim colorscheme faithfully ported from the [City Lights](https://citylights.xyz/) syntax theme for VS Code.

Colors are extracted directly from the official [`city-lights-syntax-vsc`](https://github.com/Yummygum/city-lights-syntax-vsc) theme JSON to keep the look and feel consistent across editors.

## Installation

```vimscript
Plug 'r1cardohj/citylights.vim'
```
